## 3. 必须保住的 S1 行为

1. 草稿的 owner/session/revision、材料 hash、用户接受字段、确认身份仍由服务端校验；不能只禁用按钮。
2. 每次云派发紧邻 HTTP 唯一预占；模型禁令优先于预览同意。已发送但未知不自动重试；计量不能因为结果没发布而退款或重置。
3. 指引新增、替代、撤回或过期均使旧理解退出有效视图；没有新事件跨过时间边界也一样。旧成功与旧失败均不能盖新状态。
4. 预览的云处理同意不授权额外 OCR、embedding、搜索或后台工作。确认后材料本地同步仍复用原 Capture/Attachment 与逐份身份/lease。
5. 清理失败保留文件键和重试责任；撤回、到期、项目删除后不得从理解、接受字段或临时副本重新暴露原文。禁用新入口不能取消清理责任。
6. Web URL 恢复、提交回包丢失重试、鸿蒙页面离开/换账号均保留身份栅栏。新 UI 不覆盖用户正在编辑的字段。
7. 文本 ENTAILS、工具完成、用户报告、独立核验分开；Action 完成保留原 `resultCardId`，Mission 成功不能由新文案推导。
8. 保持原 Conversation、Investigation、Mission/Worker、Memory/SourcePolicy、Attention 与 Handoff；不固定工具顺序，不新建 Runner/Planner/通知系统。
