- 不裁剪掉页面中的“Mock 模式 · 离线可演示”标识；
- 在正式 Word/PDF 中按“图1～图8”连续编号并加中文图注；
- 若后续修改了产品名称、界面功能或 seed 数据，重新截取对应图片；
- 图片不作为“用户规模、效果提升或小艺已接入”的证据使用。
