# ProjectMemo 编辑部式项目档案 UI 设计

## 目标

将现有功能完整保留，把页面从“通用卡片集合”提升为适合比赛演示的项目档案界面：内容更聚焦、中文阅读更舒适、项目记忆和主动复用更容易被评委看见。

## 视觉语言

- 背景：暖纸白与极轻的网格/色块，不使用大面积渐变。
- 主色：深蓝墨色用于品牌、标题、主要操作；青绿色仅用于 Agent 已处理、正向行动和关键链接；砖红仅用于风险。
- 字体：沿用 Inter、PingFang SC、Microsoft YaHei 系统字体栈；标题使用紧凑字距，正文保持较宽行高。
- 表面：卡片使用轻描边、细微阴影和 16–24px 圆角；避免所有模块使用同一强阴影。
- 动效：只为按钮、链接、卡片 hover 与数据状态添加 150–200ms 过渡；尊重 `prefers-reduced-motion`。

## 页面改造

### 首页

- 英雄区改为更克制的双栏档案布局：左侧价值主张和 CTA，右侧作为“Project Memory”档案预览。
- 缩小超大标题，增加眉题、功能索引和真实卡片细节，首屏呈现“碎片 → 记忆 → 成果”的闭环。
- 三个价值点使用不同的纸质档案卡层级，替代完全相同的悬浮白卡。

### 项目列表与创建表单

- 项目列表采用档案卡片，明确场景、截止日、卡片/成果统计与进入动作。
- 表单改为清晰的字段分组和输入状态，保证中文长文本输入的可读性。

### 项目详情

- 顶部变为项目档案抬头：项目状态、场景、目标、截止日和成果入口分层展示。
- 主动提醒保留 2–4 张卡，但使用语义色条和较小图标，减少色块噪音。
- 捕获模块作为“新建项目记录”编辑器；主按钮清晰表达 Agent 处理动作。
- 知识资产流增加左侧细时间线与分型标签；关系信息收敛为档案注释，避免重复边框。
- 右栏项目概览使用轻纸张底和统计分隔线，避免与主卡片竞争注意力。

### 成果生成

- 侧栏类型选择改为档案目录，结果区以文档阅读器形式承载生成内容。
- 历史版本、复制操作、生成状态使用统一的按钮和标记体系。

## 不变项

- 不更改 API、Prisma 数据、Agent Pipeline、中文文案语义和页面路径。
- 不新增图片素材、外部字体或复杂动画依赖。
- 所有表单与现有 E2E 流程保持可访问、可操作。

## 验收

- 首页、项目详情、成果页在桌面和移动宽度下无裁切/重叠。
- 主操作、风险、Agent 状态的颜色语义一致且可区分。
- `npm.cmd run lint`、`npm.cmd test`、`npm.cmd run build` 与 Playwright 流程通过。
