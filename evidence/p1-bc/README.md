# P1-B / P1-C 实施与验收

基线：`0555b088e6efab30b9aee2019dad55b0d32afe2c`。本轮是本地隔离库、mock 模式验证；未调用 ECS 模型或部署生产。

## 实际改动

### P1-B：问答接到同一委托

- 回答新增可选的严格枚举建议：保持问答、打开已有委托、预填新委托。采用保守的显式任务规则，不让模型批准写入；明确拒绝创建的语句不提示新委托。
- 已有本人未结束委托时先核对原任务。资料不足可以预览一个只读委托，不冒充已有事实或完成结果。
- 两端均可编辑目标、预览、取消、确认创建。编辑后旧预览失效；云模型许可独立且默认不勾选。创建复用原 Mission 服务；默认不联网、不创建行动，仅允许读取、分析和保存草稿。
- 来源 AgentRun、本人会话、项目所有权、项目来源指纹和预览 hash 在服务端校验。另一条新对话、来源改变、新增待接续任务均阻止旧建议创建。创建、来源事件、消费回执原子提交；响应丢失或多端确认返回同一个 Mission。
- 新问答稳定 requestId，重复提问返回同一回答；不同载荷重用编号被拒绝。最近回答上下文最多取 12 条本人已回答消息，近 6 条各最多 1000 字，并保留这些消息中的明确否决约束。上下文是数据，不是执行授权，不推断人格。
- 聊天按 ownerUserId 隔离。旧归属不明记录保留在库中，不向当前用户猜测归属或公开；来源对话链接可精确读取超过最近 20 条之外的原回答。冷启动会把已消费建议读为原 Mission 链接；中断超过 10 分钟的问答只标失败，用户另起明确请求后才重新调用。

### P1-C：精确读回与读取失败恢复

- 新增只读 readback 接口，复用原 Mission 权限。一次读取事务返回指定问题、提案、草稿 ID/修订、归入回执、来源对话及行动复盘记录。不存在的旧对象明确报错，不切换为最新对象。
- 成果没有独立 version 字段，固定版本依靠不可变成果 ID、创建时间和来源草稿修订号；两端从回执进入同一成果。Web 使用现有 artifact 查询参数，鸿蒙复用原阅读页。
- Web 委托、鸿蒙详情/摘要/焦点/概览区分最新、上次读取、不可用。临时失败保留标时历史；401/403/404 清私有数据。身份、项目和请求代次阻止迟到响应覆盖新页面。
- 未重新读到当前状态时禁止写命令；保留目标、答复及重试编号。成功读回后恢复操作。批准、已受理、运行、草稿、归入与行动完成回执各自显示。
