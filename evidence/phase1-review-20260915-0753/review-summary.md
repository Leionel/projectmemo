## 本次复审发现并修复

### A1（已修复）

`AgentRun` 的数据库唯一约束是 `(provider, externalRequestId)`，但普通记录的业务 `requestId` 只应在项目内唯一。原实现直接把客户端 ID 写进全局唯一列，两个项目复用同一 ID 会错误返回冲突。现将持久化回执键命名为 `projectId:requestId`，原始 ID 仍保存在 trace/API 语义中；新增回归测试验证跨项目相同 ID 各保存一条。

证据：`tests/phase1Reliability.test.ts`，本目录 `review-results.json`。
