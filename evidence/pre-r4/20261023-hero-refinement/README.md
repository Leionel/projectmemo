# 公开首页 Hero 精修（2026-10-23）

## 范围与审查

修改 `app/page.tsx` 的 Hero、`app/home.module.css` 的 Hero 样式，以及 `components/SiteHeader.tsx` 现有导航的首页样式作用域。保留暖白背景、深绿、衬线主标题和已有演示。没有改动下方章节结构、工作台、登录页、业务接口或数据库。

原 Hero 重复显示导航品牌和最大 104px 的产品名，价值主张仅 52px。品牌区、定位和主标题相互竞争，1440px 屏宽下产品展示从约 780px 才开始。导航菜单约 13px、移动按钮约 11px，可读性偏弱。

## 修改

- 移除 Hero 内重复的 Logo、产品名和倒影，导航保留原品牌。
- 定位降为桌面 16px / 手机 14px 的普通说明；衬线价值主张是唯一主标题。
- 缩短说明，主 CTA 改为“体验项目接续”，仍跳转已有 `#experience`；次 CTA 保留现有登录回跳逻辑。
- 缩短 Hero 留白，产品预览使用原始截图，通过可响应的视口优先露出项目风险、判断依据和下一步。截图未重新生成或改写业务事实。
- 仅首页导航使用 `homeHeader` 作用域：高度 74px（含边线 75px）、手机 72px（含边线 73px）；Logo 32px；品牌 20–22px；菜单 16px / 500；深绿工作台按钮 15–16px / 高 44px。
- 沿用原导航组件和手机隐藏菜单行为，没有另建导航。账号页面不应用新增首页导航样式。
