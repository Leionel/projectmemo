## 模块取舍

- 巨型 Agent 首屏 → 具体项目中断情境、示例入口、内置项目的实际工作区截图。
- 四阶段装饰性切换 + 重复流程卡 → 五阶段可操作故事：记录、依据、判断、确认行动、模拟回执。
- 英文装饰标题 / 三列功能营销 / 信任口号 → 两个产品界面说明：变化对比、长期委托的真实等待与恢复条件。
- 三张场景卡 → 三行具体场景。
- 双端口号 → 具体操作路径；不把模拟器截图当物理真机证明。
- 自动滚动揭示 → 内容默认可见，保留按钮即时反馈、短过渡和原生来源对话框；减少动态效果可用。

## 自助注册追加范围：认证与成本审查

- 只有 User / AuthSession / ProjectMembership；密码使用 scrypt，Cookie 为 HttpOnly / SameSite=Lax，生产 Secure。复用这些组件，保留登录与退出 API 返回结构。
- 当前没有邮箱、重置或验证 Token；需要新增账户安全扩展表与一次性 Token，旧账号不强制迁移邮箱。contest-demo 与配置中的演示账号保留，公开注册禁止占用这些名称。
- 项目由 membership 授权，委托另校验 ownerUserId；新账号不自动绑定任何已有项目。扩充跨用户覆盖，包含记忆、行动、委托和成果读取与写入。
- 云模型密钥为部署级配置，注册后若直接沿用现有调用路径会形成成本暴露。新增账户默认每日云调用额度为 0；在聊天、嵌入、图片、委托和搜索的实际付费入口实施服务端额度检查，不仅禁用前端按钮。
- 新邮箱与一次性 Token 持久化；数据库只保存 Token 哈希。重置后撤销既有会话，验证与重置 Token 按用途区分并限制有效期。
- 尚无邮件服务配置。实现 SMTP 投递与明确失败状态；隔离测试使用邮件适配器，不伪称已投递真实邮件。
