# R3 与 ECS Web 发布分支合流

合并父版本：master/R3 `21cc5fd` 与 ECS 当前 Web 发布版 `a7e3676`。在独立 worktree 验证，原工作区的签名配置、界面、测试及生成文件未提交修改均保留。

## 最终行为

- 保留公开 Web 页面的 Nginx 转发、登录页不展示预置凭据、只允许站内项目路径回跳。
- 保留 R3.0–R3.4 Mission Runtime、独立 Worker、审批、资料接续、成果归入和两端接口。
- 提醒问答的两份等效修复自动合并，没有新增重复实现。
- 项目列表 GET 增加兼容重载：Next 路由获得显式 Request 类型，旧匿名探针的无参调用继续返回401；HTTP返回契约不变。未修改历史探针或验收回执。
- 回执测试直接校验持久JSON结构和两类来源引用，修复干净构建的类型访问错误；新增无参探针鉴权回归及公开登录/外域回跳浏览器回归。

## 验证边界

完整命令、退出码、用例数与来源文件hash见 results.json。验证使用 Node 24、当前lockfile及独立依赖安装；Prisma生成在合并目录内，迁移仅作用于该目录的test-vitest.db和E2E独立库，没有seed或迁移生产/开发真实库。E2E模型为mock、Mission执行为fixture。

之前18项认证失败来自隔离库没有User表；显式迁移后关闭。之前Webpack路由类型失败与旧匿名调用兼容性同时修复。默认生产构建仍有既有的attachmentStorage全项目NFT追踪警告。

本记录不证明ECS部署、Nginx加载、真实模型/搜索调用或目标设备验收。未覆盖服务器现有.env、签名或数据，未代执行服务器命令。
