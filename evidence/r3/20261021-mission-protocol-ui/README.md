# Mission 协议与面板修复（2026-10-21）

基于发布版本 ff7c7af。用户在 ECS 的两个任务均在成功读取/检索后连续两次 MODEL_PROTOCOL_ERROR。旧版未记录原始失败类别，不能从旧记录确定是截断、JSON 还是 Schema 错误。

- DeepSeek JSON 模式请求合法 JSON，并在提示中给出实际决策 Schema；保留原生工具调用。
- 完整 fenced JSON 可解析，残片/解释文字/无效字段或工具参数均拒绝；长度截断不执行。安全诊断只保存类别、字段路径、长度、finish reason 和纠错提示，不记录原始回复、解析器消息或密钥。
- 失败调用结算已有用量，部分用量保持未知标记；包括公开查询生成的子调用。截断后的主决策可申请 2000 tokens，与预留一致，原总预算不变。连续失败仅纠错一次，成功进展/人工恢复后另起一次纠错窗口，保留步骤/成果/审批。
- 面板采用列表/详情分栏、截断长目标、分离状态与执行记录/成果/设置；兼容旧通用错误提示。请求代次防止旧轮询覆盖新选择，切换项目重建本地状态，创建失败保留输入。
